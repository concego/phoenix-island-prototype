Phoenix Island — teste de caminhada em 3D

Movimento: W norte, S sul, A oeste, D leste. Ao pressionar, o personagem vira para a direção fixa do cenário; mantendo a tecla pressionada, caminha.

Olhar: setas esquerda/direita olham para os lados; cima/baixo olham para cima/baixo sem mover o personagem. A descrição aparece abaixo da cena e é anunciada pelo leitor de tela. Pressione C para anunciar as coordenadas X, Y e Z.

Sons: passos ao caminhar; tom agudo para subir a colina, grave para descer; alerta pulsante que fica mais agudo ao se aproximar do limite do campo e um som distinto ao alcançá-lo. O áudio começa após a primeira tecla de movimento, conforme a política do navegador.

Este navegador ou dispositivo não disponibilizou WebGL para a cena 3D.
Descrição: posição inicial num pequeno campo com uma colina e uma árvore. Use as setas para olhar, ou C para anunciar as coordenadas.
